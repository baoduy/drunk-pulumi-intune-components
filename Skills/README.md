# Drunk Pulumi Intune Components - GitHub Copilot Skills

This folder contains specialized GitHub Copilot skills for working with the drunk-pulumi-intune-components library. These skills help developers understand, use, and contribute to the library more effectively.

## Available Skills

### 1. **library-overview.md**
Overview of the library structure, purpose, and key concepts for Microsoft Intune management with Pulumi.

### 2. **component-usage.md**
Guide for using the various Pulumi components provided by the library, including IntuneManagement, DeviceConfiguration, and device-specific policies.

### 3. **development-workflow.md**
Instructions for developing, building, testing, and publishing the library, including TypeScript compilation and package management.

### 4. **intune-management.md**
Detailed guide for using the IntuneManagement component to manage macOS policies, compliance, and device configurations.

### 5. **device-policies.md**
Comprehensive guide for creating and managing device policies (compliance, antivirus, disk encryption, firewall) using the library's components.

### 6. **best-practices.md**
Best practices for using the library, including type safety, error handling, authentication, and resource organization.

### 7. **troubleshooting.md**
Common issues and solutions when working with the library, including build errors, authentication problems, and Microsoft Graph API issues.

## How to Use These Skills

These skills are designed to work with GitHub Copilot to provide context-aware assistance. When working with this repository:

1. GitHub Copilot will automatically reference these skills to provide better suggestions
2. You can ask Copilot questions like:
   - "How do I create a macOS compliance policy?"
   - "What's the proper way to configure antivirus settings?"
   - "How do I build and test this library?"
   - "What are the authentication requirements?"

## Contributing

When adding new features or components to the library, update the relevant skill files to ensure the team has up-to-date guidance.
